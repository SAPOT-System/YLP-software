* YLP SAPOT MOBILE APP and WEB PORTAL

This is a repository for the accomplishment of the software requirements of
SAPOT. The deliverables of this repository are the following:
1. a mobile application that is able to provide the following services through
   a LAN:
   - messaging
     - LAN
     - SMS
   - voice call
   - video call
   - GPS sharing  (for authenticated users only)
2. a web app for admins that has:
   - user dashboard
   - locating users through GPS
   - network analytics
3. a server that provides services to the network such as
   - authentication and account recovery
   - message sync and WebSocket signalling relay
   - GPS
   - admin management
   - GSM/SMS gateway proxy
   - MikroTik router telemetry
4. a GSM module that bridges the server to a serial-attached GSM modem for
   SMS delivery when LAN messaging is unavailable
5. a captive portal (MikroTik hotspot login pages) shown to users joining the
   network
6. an offline map tileserver for the GPS map

** NOTE
Always use the flake.nix for downloading the dependencies during development
