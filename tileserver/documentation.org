* How to run the tile server

** Running temporarily
1. download the ~.mbtiles~ file: [[https://drive.google.com/file/d/1UVakmRkrHaz2J1cgCIbkAHsHDW9SYwLq/view?usp=sharing][link to .mbtiles]]
2. place it in the same directory as this documentation.org file
3. run the script ~deploy-tiling-server.sh~


** Running the server in detached mode
1. download the ~.mbtiles~ file: [[https://drive.google.com/file/d/1UVakmRkrHaz2J1cgCIbkAHsHDW9SYwLq/view?usp=sharing][link to .mbtiles]]
2. place it in the same directory as this documentation.org file
3. run the script ~deploy-tiling-server-detached.sh~

** Example usage
The code below shows the sample usage of the application
#+BEGIN_SRC html
  <!DOCTYPE html>
  <html>
    <head>
      <title>TileServer GL Basic Preview</title>
      <meta charset="utf-8" />
      <meta name="viewport" content="width=device-width, initial-scale=1.0">

      <link rel="stylesheet" href="https://unpkg.com/leaflet@1.9.4/dist/leaflet.css" />
      <script src="https://unpkg.com/leaflet@1.9.4/dist/leaflet.js"></script>

      <style>
        #map { height: 100vh; margin: 0; }
        body { margin: 0; }
      </style>
    </head>

    <body>
      <div id="map"></div>

      <script>
        // Center: Batangas / South Luzon
        const map = L.map('map').setView([13.646, 121.508], 8);

        // IMPORTANT: this must be a TILE endpoint, NOT the # URL
        const tiles = "http://localhost:8080/styles/basic-preview/{z}/{x}/{y}.png"; // or replace localhost with address of server

        L.tileLayer(tiles, {
        maxZoom: 18,
        attribution: "&copy; OpenStreetMap contributors"
        }).addTo(map);
      </script>
    </body>
  </html>
#+END_SRC
