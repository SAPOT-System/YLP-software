# Admin Management

Backend admin surface for operating SAPOT during a deployment: managing users and roles, banning disruptive accounts, publishing announcements, reviewing activity logs, and monitoring router telemetry. Consumed exclusively by a separate Next.js admin frontend — mobile app users never interact with these endpoints.

Server-mediated; no P2P path.
