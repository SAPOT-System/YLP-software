#+title: How to run the react native environment

Full setup instructions (Nix install, dev shell, dependency install) live in the root docs: [[../docs/getting-started/mobile-app-setup.md][docs/getting-started/mobile-app-setup.md]]. This file covers WSL/Android troubleshooting tips and DB schema references not covered there.

** TIPS
This section tackles the common errors that I encountered when running the react native environment.
*** Running the Android virtual machine
If you are using WSL2 it is better to install the Android studio natively in Windows then link it to WSL2. You can follow this guide [[https://reactnative.dev/docs/set-up-your-environment][Android studio + WSL2 guide]] (follow the *Android Development Environment*)


*** ADB cannot find the devices
If after running the ~nix develop~ command and the command ~adb devices~ does not show your device run the following:
#+BEGIN_SRC
# run this after you've entered the "nix develop" command
magic-fix                     # will make the phone think the server is running locally
reloadADB                     # will reload the adb server and output the newly detected devices
start-local-android           # command to run the "npx expo start" locally and in android mode
#+END_SRC

*** WSL not able to detect plugged in android devices
Run the following commands in the Powershell (note: not inside WSL)
#+BEGIN_SRC powershell
winget install --interactive --exact dorssel.usbipd-win
usbipd list
#+END_SRC
The last command will output something like:
#+BEGIN_SRC powershell
BUSID  VID:PID    DEVICE                                                        STATE
1-4    04e8:6860  SAMSUNG Android, USB Composite Device                         Not attached
1-10   046d:c52b  Logitech USB Input Device                                     Not attached
#+END_SRC
Select the BUSID of your device and enter the command
#+BEGIN_SRC
sudo usbipd bind --busid 1-4
usbipd attach --wsl --busid 1-4 --auto-attach
#+END_SRC

Go back to WSL and do the following
#+BEGIN_SRC
cd /path/to/flake.nix/directory
nix develop
reloadADB
#+END_SRC

it should work now

*** Notes:
- you need to download EXPO GO in your phone for this to work
- if you are using VSCode you need to restart the language server to remove the erroneous errors ~control + shift + p~ then enter ~Typescript: Restart TS Server~
