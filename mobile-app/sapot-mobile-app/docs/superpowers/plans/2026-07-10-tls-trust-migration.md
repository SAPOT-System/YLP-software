# TLS Trust Migration — CA-pinned, name-stable, runtime-provisioned

> **For agentic workers:** implement task-by-task; each task ends in an independently testable deliverable. Steps use checkbox (`- [ ]`) syntax.
> **Final home:** copy this file to `mobile-app/sapot-mobile-app/docs/superpowers/plans/2026-07-10-tls-trust-migration.md` when execution starts (design doc: `~/.claude/projects/-home-adamskieee-Documents-dev-YLP-software/specs/2026-07-10-tls-trust-architecture.md`).

**Goal:** Let devs/QA change the server IP *and* certificate without rebuilding, while production TLS trust stays OS-locked — by moving from a static leaf-pinned `network_security_config.xml` to a **private-CA-pinned** trust model delivered through a **runtime Android `X509TrustManager` + OkHttp `Dns` resolver** (custom `OkHttpClientFactory` in a local Expo module), with a **dev/QA-only provisioning screen** (manual host + QR + PEM import) and **mDNS auto-discovery** of the server IP.

**Architecture:** The URL host becomes a fixed name `server.sapot.lan` (in the cert SAN, so hostname verification always matches); a custom OkHttp `Dns` maps that name → the runtime-configured server IP (from mDNS or QR/manual), so IP changes need no rebuild and no OS hosts file. Trust anchors are a bundled default **CA** (prod baseline, immutable) plus an optional runtime CA loaded from `filesDir` that is honored **only in debug/QA builds**. All app HTTPS/WSS traffic (axios REST, RN WebSocket, map tiles) rides the Android OkHttp stack, so one factory covers everything.

**Tech Stack:** Expo SDK 54 / RN 0.81.5 (New Arch on, Kotlin, CNG — `android/` is gitignored), local Expo module (`modules/sapot-trust`), Expo config plugin (`app.config.ts`), OkHttp `OkHttpClientProvider`, `expo-secure-store`, `expo-camera` (QR, already a dep), `react-native-qrcode-svg` (already a dep), `@react-native-documents/picker` (PEM import, already a dep), `react-native-zeroconf` (mDNS, already a dep), Jest + `@testing-library/react-native`.

## Global Constraints

- **Scope:** Phase 0 (PKI/ops) → Phase 1 (static CA-pin) → Phase 2 (native module) → Phase 3 (provisioning UI + mDNS). **Excludes** signed `/provisioning/bundle` remote rotation.
- **Package manager:** `pnpm` (not npm). Verify per component: `pnpm run typecheck && pnpm test && pnpm run lint` (`pnpm run testAll` for cross-cutting).
- **Commit format:** `type(scope): summary` on a `feature/` branch — never commit to `main`/`develop` directly. No attribution footer.
- **CNG:** `android/` is regenerated by `expo prebuild`; **never** hand-edit `android/**` — all native wiring goes through the local Expo module + config plugin.
- **Stable name:** `server.sapot.lan` is the canonical server hostname (constant `SERVER_NAME`). Field builds (preview/production) always use it as the URL host. Dev keeps `EXPO_PUBLIC_DEV_HOST`.
- **Security invariants (non-negotiable):** never an empty/`true`-returning `checkServerTrusted` or `hostnameVerifier`; runtime CA honored only when `BuildConfig.DEBUG` (dev/QA); anchors live in app-private storage only; provisioning always parses the X.509 and surfaces its SHA-256 fingerprint for out-of-band confirmation; mDNS may set the *address* but is never a trust input.
- **Do not touch:** the P2P TCP path (`tcp-client-adapter.ts`) — it is plaintext + app-layer NaCl, has no TLS, and is out of scope. WebRTC (DTLS fingerprint) is unaffected.

## Context / why

Today `app.config.ts`'s `withNetworkSecurityConfig` writes a **static** config: prod trusts only `@raw/server_cert` (a self-signed **leaf**) for the hardcoded domain `192.168.0.100`. Changing the server IP breaks TLS on two axes (the `domain-config` no longer matches, and the leaf SAN no longer matches the IP); changing the cert means a new `res/raw/server_cert.pem` → `expo prebuild` → rebuild. `config/runtime.ts` already lets you swap the *URL* at runtime (`setRuntimeHostOverride`) but the compiled trust config can't follow. This migration makes the trust anchor **data** (a CA, runtime-loadable) and decouples the cert identity from the IP (stable-name SAN + app-side `Dns`), so dev/QA reconfigure without rebuilding while production stays OS-locked by build type.

## Corrections folded in from code exploration
- REST is **axios** (`features/shared/core/api/client.ts`), not `fetch` — still OkHttp-backed via the XHR adapter, so covered by the factory.
- **No TCP TLS** exists; the P2P path is NaCl over plaintext TCP. Removed from scope.
- **mDNS is device↔device** (`_lanchat._tcp`, `discovery-service.ts`); the server advertises nothing today. Auto-discovery of the server requires a **new** server-host advertisement (Phase 0/3, ops) + a **new** browse type in the app.
- A **manual server-host UI already exists** (`custom-drawer-content.tsx` `ServerHostInput`, `mode-select.tsx`) using `setRuntimeHostOverride` + `saveServerHostOverride`. Phase 3 extends this pattern rather than inventing one.

## Key architecture decisions
1. **Field vs dev split.** `__DEV__` behavior in `runtime.ts` is unchanged (uses `EXPO_PUBLIC_DEV_HOST`, cleartext for Metro). Preview/production URL host becomes the constant `SERVER_NAME = "server.sapot.lan"`; the server **IP** is provided at runtime and resolved by the native `Dns`.
2. **Two runtime values, one native module.** JS pushes into the native module: (a) the server IP → `Dns` map `server.sapot.lan → ip`; (b) optionally a runtime CA PEM (dev/QA only). Both persist in `filesDir` so the native side can load them at process start (`OnCreate`) before JS runs.
3. **Injection point.** The local Expo module registers the OkHttp factory in its Kotlin `OnCreate` (idiomatic Expo, avoids hand-editing the gitignored `MainApplication.kt`). The config plugin only copies the default CA asset into the prebuilt tree.
4. **Trust precedence.** Active anchors = bundled default CA (always) ∪ runtime CA (only if `BuildConfig.DEBUG`). Fingerprint = SHA-256 of the active runtime CA if present, else the default.
5. **Existing override UI** is repurposed in field builds to set the **server IP** (fed to `Dns`) while the URL stays `SERVER_NAME`; in dev it keeps its current meaning.

  -keyout server_ca.key -out server_ca.pem \

openssl req -newkey rsa:2048 -nodes -keyout server.key -out server.csr \

- [ ] **Step 1: `SapotTrustStore.kt`** — load default CA from assets, optional runtime CA from `filesDir` (debug only), server address from `filesDir`; build trust primitives:
```kotlin
object SapotTrustStore {
  private const val RUNTIME_CA = "sapot_runtime_ca.pem"
  private const val ADDR_FILE = "sapot_server_addr.txt"   // "hostname\nip"
  @Volatile private var addr: Pair<String, String>? = null

  fun init(ctx: Context) { addr = readAddr(ctx) }

  fun setAddress(ctx: Context, host: String, ip: String) {
    File(ctx.filesDir, ADDR_FILE).writeText("$host\n$ip"); addr = host to ip
  }
  fun getAddress(): Pair<String, String>? = addr
  private fun readAddr(ctx: Context): Pair<String, String>? =
    File(ctx.filesDir, ADDR_FILE).takeIf { it.exists() }?.readText()
      ?.split("\n")?.let { if (it.size == 2) it[0] to it[1] else null }

  fun setRuntimeCa(ctx: Context, pem: String) {           // caller enforces debug-only
    File(ctx.filesDir, RUNTIME_CA).writeText(pem)
  }
  fun clearRuntimeCa(ctx: Context) { File(ctx.filesDir, RUNTIME_CA).delete() }

  private fun anchors(ctx: Context): List<X509Certificate> {
    val cf = CertificateFactory.getInstance("X.509")
    val out = mutableListOf<X509Certificate>()
    ctx.assets.open("server_ca.pem").use { out += cf.generateCertificate(it) as X509Certificate }
    if (BuildConfig.DEBUG) File(ctx.filesDir, RUNTIME_CA).takeIf { it.exists() }
      ?.inputStream()?.use { out += cf.generateCertificate(it) as X509Certificate }
    return out
  }

  fun trustManager(ctx: Context): X509TrustManager {
    val ks = KeyStore.getInstance(KeyStore.getDefaultType()).apply {
      load(null); anchors(ctx).forEachIndexed { i, c -> setCertificateEntry("sapot-$i", c) }
    }
    val tmf = TrustManagerFactory.getInstance(TrustManagerFactory.getDefaultAlgorithm())
    tmf.init(ks); return tmf.trustManagers.first { it is X509TrustManager } as X509TrustManager
  }
  fun sslSocketFactory(ctx: Context): SSLSocketFactory =
    SSLContext.getInstance("TLS").apply { init(null, arrayOf(trustManager(ctx)), null) }.socketFactory

  fun dns(): Dns = Dns { hostname ->
    val a = addr
    if (a != null && hostname == a.first) InetAddress.getAllByName(a.second).toList()
    else Dns.SYSTEM.lookup(hostname)
  }
  fun activeFingerprintHex(ctx: Context): String? = anchors(ctx).lastOrNull()?.let {
    MessageDigest.getInstance("SHA-256").digest(it.encoded)
      .joinToString(":") { b -> "%02X".format(b) }
  }
}
```
